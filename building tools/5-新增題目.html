❓ 工具 5 - 新增題目

建立題庫或題目生成器

🎲 生成器型

隨機生成題目
適合數學計算

📚 題庫型

固定題目庫
適合國語、選擇題

用於前端判斷如何顯示答案輸入框

範例：整數加法生成器

const max = { easy: 99, medium: 999, hard: 9999 }[difficulty]
const a = Math.floor(Math.random() * max) + 1
const b = Math.floor(Math.random() * max) + 1
return {
  question: `${a} + ${b}`,
  answer: a + b,
  type: 'integer',
  displayAnswer: (a + b).toString()
}
